# Créditos e origem

O **ChatDeusApp** é uma adaptação independente do projeto
[ChatGodApp](https://github.com/DougDougGithub/ChatGodApp), criado por DougDougGithub.

A base original é distribuída sob a licença MIT. O arquivo `LICENSE` preserva o aviso
de copyright e os termos da licença original.

Esta adaptação reorganiza a aplicação, adiciona interface desktop, configuração em PT-BR,
vozes brasileiras, modo OBS opcional, persistência de configuração, tratamento de erros,
testes e build automatizada para Windows.

ChatDeusApp não é afiliado à Twitch, Microsoft Azure ou OBS Project.
