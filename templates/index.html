Como usar os personagens

Na aba Personagens do aplicativo escolha uma imagem para cada jogador. Depois adicione apenas a URL acima como Fonte de Navegador no OBS. As imagens se movem quando o TTS fala; o WebSocket do OBS é opcional.

Com Falando = auto, prefixos como (bravo), (animado), (triste), (gritando) e (sussurro) também mudam o tipo de movimento.
